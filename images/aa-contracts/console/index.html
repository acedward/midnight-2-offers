UI preview — not wired yet

This is the layout for a Midnight-wallet-controlled AA account: the same Manager, but the account's owner authorizes actions with a Midnight wallet (Lace / dapp-connector or a local seed) instead of an EVM signature. Nothing on this tab performs any operation yet — it exists so the UI can be adjusted before the logic is wired. Open questions the wiring will settle: which authorization the Manager's Midnight-owner mode uses (the contract tracks an accountModes map and has a localOwnerSecret witness), and whether registration binds a wallet key or a secret-derived owner id.
